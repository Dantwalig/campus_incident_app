# Demo Script (7 to 10 minutes)

Record on an Android emulator or a real phone. Keep the Firebase Console open in a browser.

1. (0:00) Intro: name, problem, stack
2. (0:45) Register with an ALU email, show the verification screen, open the link,
   show the new user in Firebase Console under Authentication, and the users document
3. (2:00) Log in as the student, point out session handling (close and reopen the app)
4. (2:45) Submit a report with category, location and photo, show the new incidents
   document and the image in the Cloudinary Media Library
5. (4:15) Show the duplicate warning by submitting a similar report
6. (4:45) Browse My Reports and Campus feed, use search and both filters
7. (5:45) Open details, show timeline, edit and delete a report that is still Submitted
8. (6:30) Log out, log in as staff, open the dashboard, update a status with a note
9. (7:30) Log in as student again to show the status and note changed live
10. (8:00) Show the code: folder structure, a Provider, a service, firestore.rules
11. (9:00) Explain state management and access control decisions, then wrap up

Tip: prepare the staff account before recording (see README).
